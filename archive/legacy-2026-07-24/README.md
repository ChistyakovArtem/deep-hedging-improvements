# Legacy archive — 2026-07-24

This directory is a reversible relocation of the coursework-era notebooks,
results, logs, generated reports, and Python bytecode that were in the project
root before the ICAIF stage-1 experiment scaffold was introduced.

Nothing was intentionally deleted. The directory structure under `results/`
preserves every previous result folder, including uncommitted reruns. The
notebooks remain available as evidence for earlier implementation choices and
results, but no new paper experiment may write into this archive.

To recover an individual artifact, copy or move it from this directory back to
the project root. Do not restore the whole archive over the new `exp/` or
`data/` structure.
